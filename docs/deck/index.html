The shift

Agents write the code now.
Nobody checks that a human understands it.

BEFORE

Author = owner

Whoever wrote the change could explain it, and review assumed they could.

NOW

Author = agent

The person who pushes may have prompted it, skimmed it, and never read the risky line.

THE GAP

Comprehension debt

Code that ships and works, but that nobody on the team can explain when it breaks at 3am.

A silent decision

"Add retries to the payment webhook."

// src/webhook.js, after the agent's change. Tests: 3 passed
export async function handleWebhook(event, { store, gateway }) {
  if (await store.hasProcessed(event.id)) return { status: "duplicate" };
  const receipt = await withRetry(() => chargeCard(event.order, gateway));
  if (await store.hasProcessed(event.id)) return { status: "duplicate" }; // moved
  await store.markProcessed(event.id);
  return { status: "charged", receipt };
}

The retries were requested. Moving the check was silent. A repeated event now charges the card twice.

How it works

Deterministic first. The model only where it earns its place.

◆ = Gemini call, schema-enforced and token-budgeted · everything else is deterministic
Read the pushgit diff, numstat, blast radius via git grep
Prechecksdocs-only, too large, protected config
Injection scantext that tries to instruct Viva is a hard gate
Checkssilent decision, behaviour change, failure path, run in parallel
Rank & planrisk score, dedupe, max 3 questions
Examine & gradeseparate grader, worst verdict wins
Ledgerscores and hashes in git notes

Ask only where it matters

A risk score decides what's worth a question.

risk = (1 + ln(1 + blast radius)) × origin
       × (0.5 + 0.5 × untested) × (1 − team mastery)
×0.5requested by the prompt
×1inferred from the prompt
×2silent: nobody asked for it
½ / 14dmastery halves every two weeks, and drops when the code changes

Fair by design

Hard on the code. Fair to the person.

  • Grading sees the transcript only, never tone, pace or accent
  • The voice examiner never sees the rubric
  • Typing always works, even mid-exam
  • Ledger holds scores and code hashes. No diffs, transcripts or audio
  • Skip anytime, as visible "debt". Hard gates for injection and Viva's own config
  • If Viva is down or slow, the push goes through. It never holds you hostage
